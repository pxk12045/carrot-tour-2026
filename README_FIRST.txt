CARROT TOUR P5 - iPhone PWA test
================================

重要:
このアプリは index.html を「ファイル」アプリから直接開くのではなく、
HTTPSの静的Webサイトとして公開して Safari で開いてください。

最短の試し方（PC推奨）
1. このZIPを展開。
2. 展開した carrot_tour_p5_pwa フォルダを静的ホスティングへアップロード。
   例: Netlify Drop / GitHub Pages / Cloudflare Pages など。
3. 発行された https://... のURLをiPhoneのSafariで開く。
4. 共有ボタン →「ホーム画面に追加」。
5. ホーム画面の CARROT TOUR から起動。
6. 一度オンラインで開けば、P5はオフラインでも再表示可能。

確認ポイント:
- 配置図の丸をタップすると詳細カードが開く
- 血統（父・母・母父）が表示される
- 賞金順位index / 2勝index に「94頭中○位相当」が表示される
- ★、◎○△×、メモが保存される
- アプリを閉じて再度開いても入力が残る

注意:
Safariの「プライベートブラウズ」では端末保存の挙動が通常と異なる場合があります。
