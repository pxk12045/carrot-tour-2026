CARROT TOUR 2026 申込状況パッチ v22
====================================

目的
----
2026年度1歳募集馬・申込み状況の中間発表2回目（9/4 17時現在）の情報を、
各募集馬の詳細画面で「母・兄姉情報」と指数・体格情報パネルの間に表示します。

アップロードするファイル
------------------------
GitHub リポジトリ直下へ、以下3ファイルを上書き/追加してください。

1. index.html              （上書き）
2. sw.js                   （上書き）
3. application-status.js   （新規追加）

表示内容
--------
・母馬優先対象馬：
  総申込数 / 母優先＋最優先 / 母優先（一般） / 最優先

・母馬優先非対象馬：
  総申込数 / 最優先

・PDFで赤字の馬：
  「今回ランクイン」を赤いバッジで表示

・PDFに載っていない馬：
  「中間発表 掲載対象外」と表示
  ※実数は推測せず、掲載基準未満であることだけ表示します。

・共通注記：
  9/4 17時、前年比約25.3%時点
  掲載基準：総申込200口以上（地方入厩予定馬は50口以上）

反映確認
--------
1. GitHubへ3ファイルを反映
2. オンラインで以下を一度開く
   https://pxk12045.github.io/carrot-tour-2026/?v=22
3. 任意の馬を開き、「母・兄姉情報」の直下に「申込状況」が出ることを確認
4. No.48など既掲載馬で数値を確認
5. PDF非掲載馬で「掲載対象外」となることを確認
6. その後、機内モードで再起動しオフライン表示も確認

補足
----
Primary v3.1、既存のapp.js、style.css、family-data.js等は変更していません。
申込状況は独立した application-status.js として追加しているため、
既存モデルやローカル保存データへ影響しません。
