CARROT TOUR v19a — 3x3 heat panel final arrangement

パネル:
指数 / 価格 / 管囲
募集時体重 / 体高 / 胸囲
想定FR（想定増加） / 将来体高（想定増加） / 将来胸囲（想定増加）

表示:
- 指数: 94頭中のv3順位（例 1位）
- その他: 実値 + 上位xx%
- 価格 / 管囲 / 募集時体重 / 体高 / 胸囲 / 想定FR / 将来体高 / 将来胸囲:
  数値が大きいほど上位として計算
- ヒートマップ: 上位=赤 → 下位=青
- 想定FRの括弧内: 募集時体重からの想定増加
- 将来体高・将来胸囲の括弧内: 募集時測尺からの想定増加

「全94頭順位」「v3指数」「募集価格」等のラベルは表示しない。
