CARROT TOUR v11 配置図パッチ

変更点
- 配置図アイコンは募集番号だけ表示。指数ランクの数字(#順位)は削除。
- アイコン背景色を総合指数ランクのヒートマップに変更（1位=赤 → 下位=青）。
- ★候補は募集番号の前に★を表示（例: ★52）。
- ★のON/OFFを詳細画面で変更した際、配置図アイコンも即時更新。
- アイコンを従来36px円形から高さ24pxの小型ピル型にして、配置図の母名を隠しにくくした。
