CARROT TOUR v19 — 3x3 percentile heat panels

詳細カード上部パネルを次の3×3に固定:
指数 / 生月日 / 価格
募集時体重 / 体高 / 胸囲
想定FR（想定増加） / 将来体高（想定増加） / 将来胸囲（想定増加）

表示:
- 指数: v3指数の数値ではなく全94頭の順位（例 1位）
- その他: 実値 + 「上位xx%」
- 生月日: 早生まれほど上位
- 価格/体重/体高/胸囲/FR/将来体高/将来胸囲: 数値が大きいほど上位
- 将来体高/胸囲の括弧内: 募集時測尺からの想定増加量
- 想定FRの括弧内: 募集時体重からの想定増加量
- 各パネル: 上位=赤 → 下位=青 のヒートマップ

削除:
- 「全94頭順位」「v3指数」「募集総額」等の旧パネル説明
- 独立した想定増加パネル
- 管囲パネル（管囲はv3寄与内には引き続き残る）
- 独立した将来体格説明ボックス

既存localStorage / ★ / コメント / 引き手評価 / 動画評価 / Export は変更なし。
