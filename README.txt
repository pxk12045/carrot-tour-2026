変更内容
--------
1. モデル寄与の表示順を全馬で固定:
   体高 → 胸囲 → 管囲 → 募集時体重 → 募集価格 → 生月日補正 → 想定FR → 性別

2. 寄与の数値を固定尺度「-100 ～ +100」に統一:
   賞金モデル・2勝モデルそれぞれについて、
   94頭全体の最大絶対寄与 = 100 として表示します。
   馬を切り替えても尺度は変わりません。

3. 測尺の直下に手術歴を表示:
   手術歴がある13頭だけ表示。
   手術歴がない馬は欄自体を表示しません。
